### Управление ресурсами через Rundeck

Джоба `infra/vm-power` останавливает и запускает виртуальные машины
кластера. Адреса мастера и worker-1 зарезервированы, поэтому после
перезапуска сохраняются. У worker-2 адрес эфемерный и меняется, но на
работу кластера это не влияет — ноды общаются по внутренней сети.

```
Было до остановки:
diplom-worker-1	RUNNING	89.169.180.0
diplom-master	RUNNING	158.160.48.155
diplom-worker-2	RUNNING	81.26.187.74

Стало после запуска:
diplom-worker-1	RUNNING	89.169.180.0
diplom-master	RUNNING	158.160.48.155
diplom-worker-2	RUNNING	158.160.201.209

Проверка доступности:
Приложение: HTTP 200
Grafana:    HTTP 200
API:        ok
```
